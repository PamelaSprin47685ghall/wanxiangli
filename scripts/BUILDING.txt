常驻构建

npm run build 自动管理本工作树的服务，不需要人手工启动 checker。
npm run build -- association 只构建指定模块及其声明的编译输入；不带模块名覆盖全库。
npm run build -- --force 忽略产物缓存，只重编选中范围。
npm run build -- --status 查询服务（查询不会启动服务）；--stop 等当前请求结束后退出。
npm run build -- --json 交出机器可读结果；不认识的双横线选项报错，不静默忽略。

默认空闲十分钟退出；默认累计 128 个项目后在构建边界轮换 worker。
WANXIANGLI_BUILD_IDLE_MS、WANXIANGLI_CHECKER_PROJECT_LIMIT 调整这两个正整数限额。
WANXIANGLI_BUILD_FORCE=1 等价于 --force。
清项目缓存保留初始化收益，不保留已检查的项目结果。
首次构建和轮换后的首次构建仍有初始化成本；全命中缓存的构建不启动 worker。

代价与边界

常驻用空闲时占着的内存换初始化时间。无改动的构建不调用 FCS，只剩通信开销，可能比不常驻更慢。
每个真实工作树一个发布者：归属靠原子改名取得，内含 PID、启动时间与随机代号；旧归属移入不可覆盖的旧代目录。
worker 只写临时产物，服务确认输入与归属后才发布；客户端断开不会把未知结果当成成功。
跨模块发布中途出 I/O 错，部分模块可能已更新，该次失败结果不能用于发布。

尚未覆盖：Windows，以及真实 Node 二进制升级。构建期改动输入的检测按缓存边界、解析完成与发布边界三处分固定，不靠定时碰运气。

已知旧失败（与常驻改动无关，未在这里处理）：警告断言、接口期望、ToolResultBound 行为、session 测试语法错误。

某一次测量的秒数与内存峰值不写在这里：那类数字一出树就过期，要考古读 git 历史，或本地分支
codex/checker-resident-evidence-20261027 的完整原始记录。当前模块数与产物清单以 package.json 的 exports 为准。
