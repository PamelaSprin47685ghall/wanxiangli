常驻构建

npm run build 自动管理本工作树的服务，不需要 agent 手工启动 checker。
npm run build -- association 只构建指定模块及其声明的编译输入。
npm run build -- --force 忽略产物缓存。
npm run build -- --status 查询；npm run build -- --stop 停止。

默认空闲十分钟退出；默认累计 128 个项目后在构建边界轮换 worker。
WANXIANGLI_BUILD_IDLE_MS、WANXIANGLI_CHECKER_PROJECT_LIMIT 可调整这两个正整数限额。
清项目缓存保留初始化收益，不保留已检查的项目结果。
首次构建和轮换后的首次构建仍有初始化成本。
