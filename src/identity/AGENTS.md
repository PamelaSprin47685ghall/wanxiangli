# identity

层：内核。不得 import 任何宿主 SDK。

# AXIOM

1. [使用者] 不同种类的东西不能被当成同一个；把甲的标识递给乙，系统必须当场拒绝。
    - 理由：标识混用会把动作做到错误的对象上，而这个对象可能是真实外部资源。

# LEMMA

1. [本模块 AXIOM 1] 每种标识是不透明包装，跨类型不可比较、不可拼接。
    - 推理：可互转的类型等于一种类型；两种类型必须由类型系统分开。

2. [本模块 AXIOM 1] 标识的描述串只供人读与诊断，不再解析回标识。
    - 推理：能反解析就说明标识其实是字符串，可互换性又回来了。

3. [本模块 AXIOM 1; 总规则 LEMMA 4] 一个会话在一次逻辑运行内的角色只记录一次，不随执行者变。
    - 推理：总规则 LEMMA 4 说用户原文不可逆、机器的话可重述。角色属于用户当初的选择，因此属于不可逆的一侧，不该被重试改写。
