# assembly

层：组装。只接线，不做决定。

# AXIOM

1. [使用者] 接线层出了问题，业务逻辑本身还是对的。
    - 理由：接线是"把谁接到谁"的问题，不是"该做什么"的问题。两者混在一起，改一次接线就得重新论证业务规则。

# LEMMA

1. [本模块 AXIOM 1] 本包只做：装配顺序、依赖注入、路由、生命周期、排空与释放。
    - 推理：这五件事的共同点是它们不产生业务判断。

2. [本模块 AXIOM 1] 本包不实现其他包的决策、恢复或分类，也不存执行位置。
    - 推理：一旦在这里做决策，同一件事就有两个 owner；存执行位置则会把调用栈上的东西搬到字段里。

3. [本模块 AXIOM 1] 物理实现（时钟、进程、事件存储、宿主）只在本包绑定到内核的接口上。
    - 推理：绑定只有一个地方，替换实现就只需要改这一处。
