# provider-calibration — 实测 provider 校准

本包是进程内会话 provider 观测的唯一所有者。在总流程中，它如实记录模型服务实际返回的上下文用量与上限观测，为配对提示和运行边界提供客观数据依据。

## 状态所有权
- 会话级状态字典独占拥有各 session 最新已观测的缓存用量与声明上下文上限。
- 库不负责从物理 HTTP/SDK 包络中提取数值，不猜 token 计数，不持有 Journal 或计费规则。

## AXIOM
1. [使用者] 报告给模型的缓存用量与上下文上限必须来自 provider 实际观测，不从 token 计数猜测。
2. [开发者] 两种观测由同一个会话状态 owner 保存；读值不能暴露内部可变别名。

## LEMMA
1. [AXIOM 1, 2] 每个 session 的最新用量与声明上限分别更新，未知项返回 null，不推断缺失项。
2. [AXIOM 2] session 退出同时清掉两种观测，避免复用时读到过期数据；进程退出可清空全部状态。
3. [AXIOM 1] 物理观测的来源由宿主判断，库只接收实际取得的观测值。

## SPEC（调用方流程）

1. **观测记录与读取**：
   - 宿主从实际底层响应中观测到用量或上下文上限时调用记录接口。用量与上限独立更新，未曾观测到的项读取时返回 null，不设隐含默认值。
   - 读取快照返回不可变数据视图，不暴露内部字典的可变别名。
2. **会话生命周期与清理**：
   - 当会话退出或被销毁时，调用方触发会话清理，原子释放该会话的观测记录，避免后续新建同名会话误读陈旧数据。
   - 宿主支持全量重置通道用于进程退出与测试隔离。
