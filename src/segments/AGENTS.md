# segments

层：内核。纯计算，不得 import 宿主 SDK；不读目录、不读写文件、不删除、不加锁——只在调用方读出的名字与字节上计算。逐行规范解码只 import `wanxiangli/events`。npm 入口 `wanxiangli/segments`。

# AXIOM

1. [使用者] 一个 writer 写下的全部事实，重新打开后必须作为同一条逻辑流读回；目录里多出一个怪名字不能让整个存储打不开，也不能把一个 writer 的流拆成两个。
    - 理由：段名就是持久格式的一部分；名字读错，要么丢流、要么串流，事后无法分辨。

# LEMMA

1. [本模块 AXIOM 1] 段名是 `<writerId>-dddd.ndjson`，dddd 恰好四位 ASCII 数字，由 `%04d` 写出。别的 Unicode 数字不是段号。
    - 推理：旧实现用 `Char.IsDigit`（Unicode Nd）判段名、再用整数解析取序号；一个 `x-٠٠٠٠.ndjson` 通过前者、在后者抛错，整个事实目录无法装载。

2. [本模块 AXIOM 1] 序号只能是 0..9999；越界必须抛错，不能写出五位名字。
    - 推理：`w-10000.ndjson` 不是段名，会被读成另一个 writer `w-10000`，流被拆开。

3. [本模块 AXIOM 1] 分组：`-dddd` 名只有在同前缀序号从 0000 起连续时才并入该前缀的段系列；否则按完整 stem 作为旧式单文件的 writer。旧式 `<writerId>.ndjson` 与其段系列同组，是中断整理、导入或版本过渡的中间态，由调用方按字节裁决。
    - 推理：这是 durable-events-005/014 冻结的读取律；本包只是唯一实现，不改律。

4. [本模块 AXIOM 1] 新建的 writerId 不得为空、不得含路径分隔符或为 `.`/`..`、不得以 `-dddd` 结尾（`writerIdFault`）。命名不是创建：命名函数只要求非空、单个路径段，因为旧目录里降级为完整 stem 的 writer（如断续段 `b-0002`）整理时仍要命名自己的段系列。
    - 推理：新 id 以 `-dddd` 结尾，其旧式文件名就与另一个 writer 的段名同形；而对已存在的降级 stem 拒绝命名，会让整理在半途抛错。

5. [本模块 AXIOM 1] 一条 writer 流是完整规范行的序列：空文本是空流；非空必须以 LF 结尾（否则末尾是半行）；内行不得为空；每行按 `wanxiangli/events` 解码，第一处失败即止（`decodeStream`）。
    - 推理：半行是中断追加，空内行不是规范字节；放过任何一种，重放读到的就不是写下的事实。

6. [本模块 AXIOM 1] 旧式文件与段系列共存只是中断整理、导入或版本过渡的中间态，裁决只有一份（`coexistence`）：旧式是段系列拼接字节的前缀（含相等）→ 段系列为准；反之 → 旧式为准；双方都是完整规范流（LEMMA 5）且 EventId 不相交 → 行续接（段系列后接旧式行）；其余为分歧，失败关闭。
    - 推理：读取与整理若各写一份，二者一旦不一致，读到的流与整理后落盘的流就不是同一条；以前主仓正是两份手写。

# SPEC

1. [LEMMA 1] ASCII 四位才是段名；非 ASCII 数字、三位或五位、缺后缀、空 writer 都不是。
    - 证明：`tests/005.test.mjs`。
2. [LEMMA 2] 序号越界、非整数抛错；9999 可写。
    - 证明：`tests/005.test.mjs`。
3. [LEMMA 3] 分组与旧读取律逐项相等（固定种子随机名单的参考实现对照，含连续/断续/共存/边界名），并与名单顺序无关。
    - 证明：`tests/014.test.mjs`。
4. [LEMMA 3] 形态：只有段、只有旧式、共存、多旧式各自命名。
    - 证明：`tests/014.test.mjs`。
5. [LEMMA 4] writerId 的三种毛病各自命名，可用 id 返回 null；降级 stem 可命名自己的段系列，空名与路径分隔符拒绝。
    - 证明：`tests/005.test.mjs`。
6. [LEMMA 5] 空流、完整行、半行、空内行各自命名；行内错误原样来自 events。
    - 证明：`tests/005-coexistence.test.mjs`。
7. [LEMMA 6] 前缀两向（含相等与空系列）、行续接、重叠 id、半行、非规范字节各自裁决；固定种子 3000 组随机形态与按冻结律独立写成的参考实现逐项相等，四种结论都覆盖。
    - 证明：`tests/005-coexistence.test.mjs`。
