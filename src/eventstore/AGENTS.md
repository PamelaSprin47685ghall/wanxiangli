# eventstore

层：内核。不得 import 任何宿主 SDK。宿主只提供目录位置，见 host-omp。

# AXIOM

1. [使用者] 落盘的字节就是用户最终能拿回的东西，进程死了也必须在。
    - 理由：这是全系统唯一真正不可逆的存储后果。字节没了或变了，整条论证一起没了。

# LEMMA

1. [本模块 AXIOM 1] 一个进程一个写入者，独占自己的段文件序列；两个进程不写同一份文件。
    - 推理：两个写入者交错写同一份字节流，无法判定某一段属于谁，历史就有了两种读法（本模块 AXIOM 1）。

2. [本模块 AXIOM 1] 一次追加的见证是一整行写到文件尾并同步落盘。半行、截断行、原地覆写都不算。
    - 推理：只有已落盘的完整行，才是别人能读回来的事实。

3. [本模块 AXIOM 1] 追加的结局只有三支：已落盘、已知没写、不知道。不知道既不重发，也不当成已发生。
    - 推理：重发会真的再写一次；当成已发生会让上层以为事实存在。两者都损坏历史。

4. [本模块 AXIOM 1] 快照与索引都是派生物：可删、可重建，不得成为第二权威。
    - 推理：派生物一旦被允许回答问题，就必须回答得和事实一样准；那它就变成了第二份事实。
