# runtime — 独立执行与物理能力

在总流程中，本模块为中立核提供真实的底层物理操作能力（进程执行、伪终端、文件读写与原子编辑、输出流缓存、高精度时间与等待），让上层组装出的产品能以安全有界、可观测、防逃逸的方式与外部环境交互；本模块不认识任何具体产品或宿主。

## 状态所有权
- **Runtime** 拥有独立执行进程、通信隔离及权限沙箱边界，不向模型泄露原生宿主对象。
- **RuntimeTools** 拥有文件编辑原语与精确字面锚点算法，保持原始字符串与 UTF-16 区间无损。
- **FileSession / Filesystem** 独占拥有文件读快照、读版本校验及多文件原子写盘/回滚事务。
- **ProcessSession / Terminal** 分别拥有操作系统子进程会话与真实伪终端会话生命周期。
- **OutputSpool** 拥有有界内存缓冲及临时外存合并流。
- **Time** 提供确定性时基与物理/虚拟等待调度。
- 库不持有业务工作（Work）、工作生命周期、评审状态，也不决定交付什么时候算完成。

## AXIOM
1. [使用者] 阻塞一个程序不能阻塞宿主、其他程序、输出排空及控制请求。
   - 理由：等待中的工作仍须可观察、可控制。
2. [使用者] 独立进程不扩大模型权限。
   - 理由：执行方式不能成为绕过授权原语的通道。
3. [开发者] 物理对象拥有真实资源、退出、输出与计量，不判断程序或业务是否完成。
   - 理由：发送、信号、退出、暂停和成功具有不同后果。
4. [使用者] 已发生的效果和输出保留，未知不能伪装成成功。
   - 理由：恢复与诊断必须依赖真实事实。

## LEMMA
1. [AXIOM 1, 2] Runtime 拥有独立执行进程、隔离和通信。同步桥接只停住所属执行单元，宿主仍接收既有 SDK、输出与退出。模型只取得受控数据与原语，不取得宿主对象或跨边界可变别名。
2. [AXIOM 3; 根 LEMMA 3] RuntimeTools 拥有原语与字面锚点，保留原样字符串及 UTF-16 span，不做空白折叠；歧义事实交 program 暂停。FileSession 拥有读快照和版本校验，Filesystem 承担文件能力，不用隐式重读掩盖冲突。
3. [AXIOM 3] ProcessSession、Terminal 各自拥有进程及终端，OutputSpool 拥有输出，Time 提供物理计量与唤醒。runtime 不解释 intent，不登记程序名字，不拥有 park 表，不认识角色、评审、Work 或 deliver。
4. [AXIOM 1, 3] 物理退出只报告事实，不自行放行暂停续体。计算保护不能以跨越 call 等待的 wall-clock timeout 偷扣执行预算。
5. [AXIOM 3, 4] 请求期限与物理有界执行不同。模型 call 请求到期保留原命令；底层 ProcessSession.run 的显式 deadline_seconds、输出预算及运行硬顶继续成立。
6. [AXIOM 3, 4; 根 LEMMA 1] 信号和取消请求不是资源终态。清理确认 shell 和进程组退出；强杀报告真实信号，不保证 finally 或逃逸后代。现场丢失不依据名字或输出自动重跑。
7. [AXIOM 4] 文件变更保持单笔原子和读版本检查；失败不撤销此前独立效果。delta 不消费最终结果，退出码、信号、字节数与截断分别报告。输出文件在程序关闭后保留。

## 永久依赖边界
program 通过公开产物使用 runtime，是明确的永久单向基础依赖。runtime 不导入 program，不复制 program 的业务状态，不接收全集式上下文。

## SPEC（调用方可见流程）

1. **执行与安全隔离**：
   - 启动执行单元时，Runtime 建立独立的执行上下文并建立受控通信通道；调用发生阻塞时，仅挂起当前执行单元，宿主事件循环与并发请求不受干扰。
   - 模型执行环境严禁访问外部未授权对象、全局原型或未受控环境变量。
2. **文件系统与精确编辑**：
   - 读取文件生成当前读版本快照；保存文件时先比对磁盘最新版本与快照是否一致，发生冲突时以 `FILE_CHANGED` 显式拒绝，不静默覆盖。
   - 多文件修改必须预检全部变更，任何一处失败则按回滚清单恢复已有写入，保持原子性。
3. **进程、终端与流输出**：
   - ProcessSession 启动子进程并监控退出码与管道输出；Terminal 提供真实 pty 伪终端支持交互式命令与窗口缩放。
   - 大输出流经由 OutputSpool 自动从内存溢流至独占外存文件，超时到达或进程中断时如实报告实际输出与终态事实。
