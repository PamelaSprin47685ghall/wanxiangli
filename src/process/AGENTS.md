# process

层：内核。物理执行在 host-omp。本包只定义契约。

# AXIOM

1. [使用者] 命令是真的对世界动手；输出只是观察。
    - 理由：真实外部效果不可逆（总规则 LEMMA 1）。把输出当成完成，就会在命令还在跑的时候做下一步。

# LEMMA

1. [本模块 AXIOM 1] 只有底层的真实退出能确认物理完成。发终止信号、输出停止，都不算。
    - 推理：信号是请求，退出是事实。两者混同，上层就会在进程仍活着时以为它结束了。

2. [本模块 AXIOM 1; 总规则 LEMMA 1] 时限是承诺，不是预测。到期只终止这次等待，不制造别的事实。
    - 推理：给命令设时限是"我愿意等多久"，不是"它会跑多久"。把到期当成失败或成功，都会造出没有依据的结论。

3. [本模块 AXIOM 1] 取消向整个进程组发出，立即返回等待方；取消不宣称已经退出。
    - 推理：只杀主进程会留下孤儿子进程，继续占着资源。

4. [本模块 AXIOM 1] 输出按字节预算截尾，保留未经修改的原始尾部，不做模型摘要。
    - 推理：原始日志是数据，包括形似指令的文本。摘要是第二手材料，读错了无从核对。

5. [本模块 AXIOM 1] 同一时刻只让一个大输出执行占用共享的繁重资源。
    - 推理：几个大输出同时来，会把机器压到谁也跑不动。
