# workrecord

层：内核。不得 import 任何宿主 SDK。

# AXIOM

1. [使用者] 一段工作要有可复核的边界：从哪开始、到哪结束、这段时间发生了什么。
    - 理由：逐轮说清（总规则 AXIOM 1）要求每一轮的取材范围是确定的；范围随人而变，就无法复核。

# LEMMA

1. [本模块 AXIOM 1] 范围由轨迹区间定义，不由"谁看过"或"谁记着"定义。
    - 推理：同一段工作对不同观察者必须是同一段，否则两边说的不是同一件事。

2. [本模块 AXIOM 1] 记录分三段：开场（可选）、已沉淀的部分、尚未沉淀的尾部。
    - 推理：已沉淀与未沉淀的取材方式不同，混在一起会让读者分不清哪部分是压缩过的。

3. [本模块 AXIOM 1] 正式陈述是最后一条助手散文，不是结构化字段表。
    - 推理：结构化字段只能承载协议必需的东西；让模型把结论塞进固定字段，会把诚实叙述挤成填空。

4. [本模块 AXIOM 1] 不同接收者看同一份记录，只是选择不同视图，底层事实一份。
    - 推理：多份记录就是多份事实，迟早对不上。
