# projection — 请求投影的信息边界与输出截断

层：内核。独立 npm 入口 `wanxiangli/projection`。在总流程中，本模块负责计算发送给模型的请求上下文边界（过滤前任消息、保留本任期有效上下文）、生成规范确定的序列化字节，以及对超长工具结果实施标量安全的尾部保留截断。

## 状态所有权
- **Projection** 工厂无状态计算，独占拥有任期切点计算、请求规范字节编排与布局规划算法。
- **ToolResultBoundStore** 独占持有宿主声明的工具输出上限动态配置（`hostMaxLines`、`hostMaxBytes`）。
- 不持有磁盘或数据库连接，不直接进行网络 I/O。

## AXIOM
1. [使用者] 新任期只看见屏障之后标明属于自己的消息。触发接力的那次 review、它的结果，以及更早的交互都不可见。原始字节不改。
2. [使用者] 宿主不得编造身份；发送给模型的投影顺序不能取决于功能注册的先后。
3. [使用者] 工具输出超限截断时必须优先保留尾部信息，并保证 Unicode 标量边界完整，不产生半截乱码。

## LEMMA
1. [AXIOM 1] 切点定位在触发接力调用与其结果中较晚的一条；切点之前的消息不进入后任模型请求。
2. [AXIOM 1] 切点之后仅保留属于后任任期且非合成行的消息，未归属消息被排除。
3. [AXIOM 2] 规范字节（wire/semantic）按固定字段序与转义规则序列化，消除环境差异。
4. [AXIOM 3] `ToolResultBoundStore` 采用固定截断标记常量（`"...head truncated (tail kept)...\n\n"`），在宿主上限内安全保留尾部有效输出。

## SPEC（调用方流程）

1. **任期消息切分与投影**：
   - 传入会话完整消息历史与当前任期身份。系统依据切点规则滤除前任消息，输出仅包含本任期合法上下文的投影集合。
2. **规范化线格式渲染**：
   - 将投影对象渲染为 `wire` 或 `semantic` 字节串，字段顺序与格式保持确定性，支持前缀缓存稳定命中。
3. **工具结果尾部截断**：
   - 工具产生长文本时调用 `bound(text)`。若超出行数或字节数上限，前部内容被安全替换为截断声明，末尾内容严格按 UTF-8 字符边界对齐保留。
