# program — 命名程序与请求期限

在总流程中，操作员把要自动执行的步骤写成程序交给模型；本模块负责这些程序的命名登记、并发单飞控制、会话重放、绝对请求期限核算以及终态结算。

[程序待改] 模型侧提交入口的工具名 `todowrite-for-<role>`（`ProgramCatalog` 投影）沿用宿主工具词根，写死在核里；已登记在根《例外清单》，目标由万象通提供名字。

## 状态所有权
- **ProgramSession** 拥有会话内的程序名称注册表、调用重放记录与活动运行对象。
- **Run** 独占拥有单次运行生命周期、暂停代际（generation）、预算扣减与终态 effects 结算。
- **ProgramCatalog** 负责提供能力与方法投影字典。

## AXIOM
1. [使用者] 会话内一个名字对应一次运行，恢复继续原现场。
   - 理由：重跑会重复已经发生的效果。
2. [使用者] call 停住所属程序，宿主、其他程序及已经发起的 SDK 操作继续响应。
   - 理由：漏写 await 不能绕过单命令约束。
3. [开发者] 程序状态、期限、恢复关系及成员投影各有唯一所有者。
   - 理由：多份状态和计时器会造成隐式续期、重复恢复或扩权。
4. [使用者] 程序结束、命令退出、工具响应与业务完成分别报告。
   - 理由：局部终态不能解除仍存在的义务。

## LEMMA
1. [AXIOM 1, 3; 根 LEMMA 3] `Program()` 提供入口，`ProgramSession` 组织会话内调用重放；相同物理调用重放既有回执；新调用若占用仍处于活动或挂起（parked）的名字报 `NAME_TAKEN`；已完成名字允许重新发起新运行。
2. [AXIOM 2, 3] 脚本内执行 `call` 时，先等待此前操作结清再启动命令；操作未完成前暂停执行并停表。
3. [AXIOM 3] 请求准入时按 `UTF8Bytes(intent) * 50ms` 核定绝对执行期限；`call` 与 `unpark` 共用既有期限，不额外派发预算。期限到期时程序安全挂起。
4. [AXIOM 1, 4; 根 LEMMA 1] 代际机制隔离迟到控制；`abandon` 与会话关闭共同确认资源结清后才报告终态；已落盘效果不发生回滚。
5. [AXIOM 3, 4] 终态 effects 经 `settle` 一次性结算，保存在回执中。

## SPEC（调用方流程）

1. **程序提交与准入**：
   - 调用方传入 name、program 源码与 intent 发起运行。系统核定预算期限并登记名称；若名称已被占用返回 `NAME_TAKEN`；若属于重放调用返回原回执。
2. **执行与挂起**：
   - 程序执行 `call` 命令时暂停主流程并调度外部执行；调用 `park` 或发生锚点歧义时，程序转入挂起状态并保留已产生的副作用。
3. **恢复与收尾**：
   - 调用方通过 `unpark(name, value)` 注入恢复参数唤醒原挂起程序继续执行；通过 `abandon` 中止目标程序并结清关联物理资源。
   - 执行正常结束或抛错退出时，单次结算输出及变更并生成最终回执。
