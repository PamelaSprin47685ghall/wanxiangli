# retention

层：内核。纯计算，不得 import 宿主 SDK，不读文件、不读时钟、不删除。npm 入口 `wanxiangli/retention`。

# AXIOM

1. [使用者] 过期只能整条移除一个 writer；仍有读取义务的事实不能因为时间算错而被删。
    - 理由：删除不可逆；误删的事实无法从别处找回。

# LEMMA

1. [本模块 AXIOM 1] 保留单位是 writer 最近活动时刻的 UTC 日期：今天与昨天保留，前天及更早整条过期。日期只是 GC 分组，不携带历史语义。
    - 推理：滚动 24 小时会让同一历史在同一天内的不同时刻得出不同集合；按日分组让同次收敛共享一个截止日。

2. [本模块 AXIOM 1] 截止时刻和活动时刻都由调用方给出；本包不读时钟，不读文件。
    - 推理：同一次收敛必须用同一个 now，才有 `Retain(A ∪ B) = Retain(A) ∪ Retain(B)`；活动时刻怎么取（Journal 尾部还是文件时间）是存储组合者的事。

3. [本模块 AXIOM 1] 非有限的时刻不是“很久以前”，是调用方错误，必须拒绝而不是判为过期。
    - 推理：NaN 与任何日期比较都为假；悄悄当作过期就是删数据。

4. [本模块 AXIOM 1] writer 的活动时刻是逻辑流尾部的持久观察：最末一条 Journal 信封的有限 `ObservedAt`；尾部连续的 `ProjectionCutTail` 是前一条事实的整合元数据，不推进活动，可一路往前（跨段由调用方接续）；任何别的尾行或行已读尽都是“没有持久活动”，交还 null，由调用方退回文件时间。本包只分类调用方交来的行，不读盘。
    - 推理：活动时刻决定整条 writer 的去留；把整合元数据或无效时刻当成活动，会让本该过期的 writer 留下，或让仍要服务的 writer 被误判。

# SPEC

1. [LEMMA 1] 日边界：昨天 00:00:00.000 保留，前天 23:59:59.999 过期；与今天内的具体时刻无关；活动推进可让 writer 移到更晚的日。
    - 证明：`tests/011.test.mjs`。
2. [LEMMA 2] 同一 now 下保留集合对并集分配，筛选保持顺序并按引用交还。
    - 证明：`tests/011.test.mjs`（固定种子 300 组）。
3. [LEMMA 3] NaN、Infinity、非数字的 now 或活动时刻抛错。
    - 证明：`tests/011.test.mjs`。
4. [LEMMA 4] Journal ObservedAt 即活动；cutTail 链跨段向前；其它尾行（含旧 Journal 行之前的任何别类行）止于 null；只拉取到第一个结论为止；坏 JSON、非对象、缺字段、非字符串或不可解析时刻一律 silent。
    - 证明：`tests/011-tail.test.mjs`。
