# prefix

层：内核。不得 import 任何宿主 SDK。

# AXIOM

1. [使用者] 同样的前缀再发一次，模型那边应当能命中缓存，不要重算一遍。
    - 理由：这是省钱，不是安全。本包守的是钱，不是不可逆事实。

# LEMMA

1. [本模块 AXIOM 1; 总规则 LEMMA 1] 同一世代内，前一次发给模型的请求必须是后一次的精确字节前缀；否则这一代作废，开新的一代。
    - 推理：缓存认的是字节。中间改一个字节，后面全部失配。

2. [本模块 AXIOM 1] 世代只由已提交的证据推进，不按容量或 token 数主动切。
    - 推理：主动切会掩盖实现造成的字节漂移（总规则 LEMMA 1：这类漂移没有不可逆后果，但会把钱悄悄花掉）。

3. [本模块 AXIOM 1; 总规则 LEMMA 4] 候选前缀不得越过用户原文；用户原文的边界由 trace 定。
    - 推理：本包可以为了省钱替换历史，但替换不动用户说过的话。

4. [本模块 AXIOM 1] 候选前缀不修改已提交的世代；失败直接丢，无需回滚。
    - 推理：候选只是这一次请求的执行配置。它没落盘，就没发生过。
