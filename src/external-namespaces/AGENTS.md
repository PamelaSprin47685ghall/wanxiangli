# external-namespaces — 外部工具命名空间事实

独立 F# 包，公开入口 wanxiangli/external-namespaces。自治对象持有进程级 MCP 命名空间的已声明集合，接收宿主提供的真实名称，不读取 SDK、配置文件、角色与持久日志。

## AXIOM

1. [使用者] 历史配置已经向活会话公开的外部工具命名空间，在配置重载或另一个工作区载入后仍必须由运行时识别；不能因丢失旧名称而跳过执行拒绝。
2. [使用者] 本轮配置只向模型公开本轮实际声明的命名空间，不因进程历史并集扩大当前配置的工具投影。
3. [开发者] 外部工具识别不产生领域能力或授权；实际角色准入由独立的业务门禁处理。

## LEMMA

1. [AXIOM 1] 每次 declare 只能增加此前未声明的名称，重复及空数组保持状态不变。进程 owner 不提供撤销动作。
2. [AXIOM 2] patterns 只映射调用方本次输入，保留顺序与重复项，不把整个历史集合偷偷拼入输出。
3. [AXIOM 1, 3] matches 使用原始大小写与严格 server + 下划线前缀；不枚举或许可任意具体工具。配置字段 enabled 的物理解码属于宿主，不进入库。

## SPEC

1. tests/001.test.mjs 覆盖两份互斥配置、重载、大小写、严格前缀、重复声明与纯投影。
2. tests/002.test.mjs 用种子确定的随机操作序列，与独立并集和字符串前缀模型逐步比对。
3. 主仓 capability-enforcement-007 的真实 Host config 和 tool.execute.before 门禁覆盖物理前后连线，且旧 owner 删除；成功的离线门禁不等同于真实外部工具部署。
