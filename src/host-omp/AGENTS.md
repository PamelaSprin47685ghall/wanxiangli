# host-omp

层：GAP。唯一 import 宿主 SDK 的包。其余包不得 import 本包。

# AXIOM

1. [使用者] 宿主给的事实只能观测，不能猜；宿主没给的，宁可标缺失。
    - 理由：本包与宿主同寿（总规则 AXIOM 2）。它猜错，内核拿到假事实，逐轮说清就退化成编故事（总规则 LEMMA 5）。

2. [使用者] 换一个宿主时，只有这一个包跟着换。
    - 理由：总规则 AXIOM 3 的全部意义在于此。

# LEMMA

1. [本模块 AXIOM 1] 把宿主的装载、消息、请求变换、工具、子会话、执行、信号观测翻译成内核要的实例；翻译只做形状转换，不做判断。
    - 推理：一旦在这里做判断，判断就被绑在宿主形状上，宿主一换它就没法迁移。

2. [本模块 AXIOM 1] 宿主快照里没有的东西标为缺失，不补默认值。
    - 推理：默认值一旦填进去，读的人分不清"宿主说没有"和"我们猜没有"。

3. [本模块 AXIOM 2] 本包可以整体删除；删掉后内核仍然成立，只是没有宿主可用。
    - 推理：这是分层是否真实的判据（总规则 SPEC 1、SPEC 3）。
