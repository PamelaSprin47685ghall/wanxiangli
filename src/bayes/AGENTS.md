# bayes — 有限离散假设贝叶斯后验

层：纯数值计算。独立 npm 入口 `wanxiangli/bayes`。在总流程中，本模块为有限假设集提供严格在对数空间内计算的贝叶斯后验概率更新，支持在极小尺度下不下溢、零先验稳定保零。

## 状态所有权
- 纯数学计算库，无内部可变状态。

## AXIOM
1. [使用者] 只有合格因子进入后验；因子必须声明依赖组、覆盖全部假设，似然值必须是 0 到 1 之间的有限数。
2. [使用者] 同一观测 id 重复投递只算一次；同组不同 id 记录被丢弃项，不被静默吞掉。
3. [使用者] 对数空间乘积与归一化，极小尺度不下溢，零先验保持为零。

## LEMMA
1. [AXIOM 1] 假设数少于 2、重复键、非法先验或无效似然均给出明确错误。
2. [AXIOM 2] 观测输入幂等处理；未声明联合因子时丢弃的冗余项在 `dropped` 中列出。
3. [AXIOM 3] 后验计算与理论闭式严格一致，全零似然返回明确错误。

## SPEC（调用方流程）

1. **后验推断**：
   - 调用方传入初始先验、假设集合与观测因子调用 `infer`。系统在对数空间完成乘积与 log-sum-exp 归一化，返回后验分布及已消费观测。
2. **输入检查**：
   - 遇到非法假设或缺失覆盖的因子时返回带种类的错误，不让 NaN 或除以零的结果进入后验。
