# Provider 失败预算

这个入口帮助调用方在已确认的请求失败后限制自动重试，避免同一次失败因重复观察而反复计费。它不解释宿主错误，不发送请求；公开面见 `index.d.ts`。

`ProviderFailureBudget` 拥有不可变预算的转移规则：精确 attempt 去重、连续失败单步推进、耗尽、成功清零和重复失败的答复。默认上限 10，去重窗口 32；持久投影仍由调用方 Journal 保存。

`DurableProviderBudget` 组合当前投影与追加能力。每次调用重新读 Current，不缓存第二份预算。授权失败先写 FailureRecorded，写成功后到达上限才写 RetryExhausted；第二次写失败时，第一条已经写入的事实保留，原错误交回，不自动补写。重复最新失败从投影回答，较旧失败返回 EpisodeSuperseded；不同 logical run 的授权拒绝写入。

成功仅在当前有非零计数时追加 SuccessRecorded；没有预算或计数已为零时不写。成功重置预算不意味着外部请求可重发。日志重复追加规则不替代 provider 效果的幂等保证。

历史事实格式、投影中既有吸收规则、SDK 分类与产品策略由原调用方适配保留，本入口不借迁移修改它们。适用根目录万象理约定。
