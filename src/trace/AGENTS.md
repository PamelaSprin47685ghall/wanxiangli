# trace

层：内核。不得 import 任何宿主 SDK。

# AXIOM

1. [使用者] 用户说过的话必须逐字节留着，一个字都不能变。
    - 理由：用户原文不可逆（总规则 LEMMA 4）。改了就再也问不回去，也无法核对系统有没有曲解。

# LEMMA

1. [本模块 AXIOM 1] 轨迹只能追加。开场捕一次不覆盖；部件按游标严格单调追加；每个 provider 运行至多一个终态。
    - 推理：可覆盖的轨迹里，"当时是什么"没有独立位置，逐轮理由就无从复核。

2. [本模块 AXIOM 1] 用户原文永远保留原始形态；任何为省 token 的重写都不得碰它。
    - 推理：AXIOM 1 是本包存在的唯一理由。允许重写一次，就有了第二次。

3. [本模块 AXIOM 1] 压缩或重锚不得删除已有轨迹。
    - 推理：重锚是换一种呈现方式，不是删掉历史。

4. [本模块 AXIOM 1] 游标与宿主的下标和轮次无关。
    - 推理：宿主的下标会随它自己的重排而变（总规则 AXIOM 2）。把轨迹位置绑在宿主下标上，宿主一重排就指错。
