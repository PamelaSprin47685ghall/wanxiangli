# trace — 原始材料与固定取材范围

公开入口为 `wanxiangli/trace`。用户交给系统的材料需要留有原件，后续展示、压缩和接力才能核对是否曲解了委托。本模块保存收到的材料和已确认的观察，不假装保存接收边界从未提供的原件。

## Trace

`Trace` 拥有单条内存观察轨迹。观察按接收次序追加；同身份、同内容重放返回原记录，冲突不追加。Opening、运行、消息和已确认部件分别表达自己的事实，不从散文推断来源或运行结束。

输入字节会复制，BOM、NUL、CRLF 与非 UTF-8 字节保持原样；文本视图解码失败返回 `null`。每个部件最多 512 KiB，每条规范 JSON 记录最多 1 MiB。没有静默淘汰或原文改写。

原始游标为 `number`，边界包含轨迹身份、游标及前缀摘要。读取使用 `(after, through]`，消息按首次观察位置选入，部件只读到固定上界。窗口里的原件和助手散文都是派生视图，不代替历史。

恢复使用调用方提供的规范记录，拒绝断链、损坏和非法领域顺序。合法前缀被截短，若没有外部保留的边界，仅靠这段前缀无法识别。内存捕获不表示已经落盘；提交和发布由外层组合者负责。

## TraceHistory

`TraceHistory` 组合 `Trace`，拥有不可变的语义历史：Opening、部件引用、按运行区分的终端、语义游标到原始游标的映射及私有缓存。它不拥有事件仓的 Current，也不读写磁盘。

- 语义序号使用 `bigint`，保留原 `int64` 的范围与计算；部件序号须严格大于已有末尾。缓存可转交给一个新候选，旧历史或另一个分支按自己的记录恢复，不能共享正在改写的 Trace。
- Opening 原文和要求完整保存。其 Trace 信封仍按既有规则截取前 512 KiB 字节；晚补 Opening 会先重建全部部件，再重建全部终端。相同 Opening 重放返回原 History。
- 部件保存正文引用、摘要和调用方提供的描述串；正文在读取时取得。宿主坐标等字段作为不透明 metadata 传递，库不解释它们。可选 `prepareMetadata` 只在游标被接受后执行，保留宿主翻译的原调用时点。
- 终端按运行去重；同引用、同摘要重放返回原 History。终端保留当时的语义末端，不推进部件序号或覆盖区间。
- `rangeFrom`、`slice`、`interval` 和 `afterCoverage` 用语义范围映射原始固定边界。覆盖区间止于最后一个部件，不自动包含后来的终端记录。
- `read` 按调用方选定的条目顺序逐项读取，允许重复条目。普通读取不计算正文摘要；读取失败返回原有上下文文字，Promise 拒绝直接传播。未知部件类型或缺少工具名，在对应正文读取成功之后才返回错误。
- `materialize` 和 `materializeTraceItems` 保留既有语义往返：TextEncoder 编码、512 KiB 分块、Trace 固定窗口、合并字节后 UTF-8 解码。工具名和媒体类型长度按 UTF-16 字符单元编码。普通 `read` 不经过这次往返。

宿主事件排序、代际选择、消息身份解析、显式摘要核对和 provider 请求组装留在调用方。返回数组和 History 自己的记录视图会复制；metadata 保持调用方不可变值的引用，不产生第二份宿主状态。

## TraceCapture

`TraceCapture` 组织原文保存与事实追加。它读取调用方当前的 History，按已解码的不透明身份辨认重入，为新部件分配游标，先写正文，再追加对应事实。每项依次结算；后项失败时，前面已经提交的材料仍然保留。正文写入的普通错误原样返回，事实提交的 Promise 拒绝原样传播，不重发整批。

同一会话的完整捕获通过 `run` 串行，复用公开 `wanxiangli/keyed-serial`；不同 key 可独立前进。对象只拥有在途合作和每批索引，不复制 Journal 的持久 Current。索引以批次开始时的历史为准，不新增批内去重。

Opening、正文终端和已保存引用分别保持自己的重入条件。receipt 从捕获前后的 History 计算；返回不代表额外的落盘保证，实际提交由调用方提供的存储参与者兑现。库不识别宿主消息字段、provenance 字符串格式、重试注入或压缩代际；这些由万象通翻译成身份键和不透明 metadata。

## 修改与自保

本模块独立构建：`node scripts/build.mjs trace`；运行时通过公开产物消费 keyed-serial，不编译其源码。Trace 的既有就近测试覆盖字节捕获和固定窗口；History 与捕获合作的差分分别在 `tests/history.test.mjs`、`tests/capture.test.mjs`。安装消费者复用 `scripts/tests/trace-consumer.mjs` 的 `history` / `capture` 模式和对应 TypeScript 文件，走 npm 公开入口；不以本地私有源码替代交付内容。
