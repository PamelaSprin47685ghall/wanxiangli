# compression

层：内核。不得 import 任何宿主 SDK。用户原文由 trace 保留，本包不得动它。

# AXIOM

1. [使用者] 历史越短越便宜，但不能拿用户原文做交换。
    - 理由：省钱是普通目标（总规则 LEMMA 1），用户原文是不可逆的一侧（总规则 LEMMA 4）。两者冲突时，后者赢。

# LEMMA

1. [本模块 AXIOM 1] 不观测模型上下文窗口有多大；不按"快满了"主动压。
    - 推理：窗口大小是宿主的实现细节（总规则 AXIOM 2），而且估算本身会变成一轮隐藏输入。

2. [本模块 AXIOM 1] 真实失败是唯一的恢复信号。
    - 推理：提前预测溢出，就要猜长度；猜错比等一次真实失败更贵。

3. [本模块 AXIOM 1; 总规则 LEMMA 4] 真实用户消息永远保留原始形态，任何重写都不得覆盖它。
    - 推理：AXIOM 1。

4. [本模块 AXIOM 1] 只处理本会话已沉淀的部分，不碰父级或跨会话材料。
    - 推理：跨界压缩会让 A 会话的历史被 B 的形状改写。
