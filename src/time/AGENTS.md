# time

层：内核。本包只定义契约；物理时钟在 host-omp。

# AXIOM

1. [使用者] 时间不是权威。业务只在显式拿到时钟时才读时间。
    - 理由：随时读全局时间，等于让"现在是几点"变成隐藏输入，同一份输入会得两个结果，事后无法复述决策。

# LEMMA

1. [本模块 AXIOM 1] 时钟与定时器都靠注入；内核不读全局时间、不排全局定时器。
    - 推理：能随手读到的东西就一定会被随手读到，隐藏输入就是这么长出来的。

2. [本模块 AXIOM 1] 截止时间是"当前时刻 + 预算"算出的值。到期只结束这次等待，不制造任何业务事实。
    - 推理：时间只是约束"我愿意等多久"，不是关于世界发生了什么。

3. [本模块 AXIOM 1] 同样的注入可以换成确定性虚拟实现；测试不靠真实等待。
    - 推理：靠真实等待的测试，结果随时序而变。
