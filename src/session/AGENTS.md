# session — 资源归属与收尾

第四刀，公开入口 `wanxiangli/ownership`，自治对象 `Ownership`。本轮明确将草稿中的唯一 owner、关联先于效果、物理容器不等于身份落实为资源范围与预留协议。它不依赖前三刀，不启动、查询或取消实际资源；作用域不是 Work 的第二套任期。

## AXIOM
1. [使用者] 一项外部资源从准备创建到确认结束，都必须有明确的收尾负责人；未知结果不能让资源消失。
   - 理由：先启动再登记、发信号就删登记，都会留下仍在动手却没人负责的资源。
2. [使用者] 收尾一个范围不能误伤别的范围；旧实例的迟到回执不能释放复用容器上的新实例。
   - 理由：会话标识与 PID 可以复用；按数量减一或按容器名删除会释放错对象。
3. [开发者] 归属规则、物理执行、持久提交与业务退休分别独立，由外侧显式组织。
   - 理由：Ownership 只回答谁尚未收尾，不能复制 Work 的退休条件、ProcessSession 的物理判断或 Journal 的提交协议。

## LEMMA
1. [AXIOM 1, 2] 作用域组成有根森林，父关系开立后不变。资源先预留在唯一作用域下；资源身份在本登记簿内不复用，返回绑定登记簿与归属的 lease 数据。
   - 推理：只有父节点已存在时才允许加入新子节点，不允许改挂，便不会形成环或无主中间状态。固定 DevOps 可以属于长期父范围，短期任期是其子范围，不必退休时迁移资源。
2. [AXIOM 1] Reserved 与 Running 都阻止关闭；Started 必须是已观察承接，Unknown 不改变状态。NotStarted 只接收确定不会启动的拒绝；Ended 接收带实例身份的真实终态，可以用于重证丢失了 Started 回执的预留。
   - 推理：没有启动回执不等于没有启动；只在明确消除了继续执行的可能后，才能释放归属。
3. [AXIOM 1, 2] Cancel 只记录请求；Drain 关闭本范围及后代的新准入，不释放现有资源。Close 仅在整个子树没有未终结资源时原子关闭子树；已关闭身份不复活。
   - 推理：关闭准入与物理完成是两件事。预留也属于未收尾资源，所以 drain/start 交错不能在边界外漏出新工作。
4. [AXIOM 2] 物理关联为 kind、externalId、incarnationId。并存的 Running 资源不抢同一物理容器；旧实例的关联不复用。终态只改变该 lease，对同容器新实例没有删除作用。
   - 推理：容器可复用，但实例必须明确区别；收到旧结束记录时，不能依容器名释放新登记。
5. [AXIOM 1, 2, 3] 只记录已接受的归属消息。重放由本库恢复纯内存状态，不执行外部操作。Applied 不等于 Committed；跨进程使用须由组合者通过单一日志和修订比较确认，预留提交成功后才可开始外部效果。
   - 推理：把本地对象响应当作持久许可会产生并发和崩溃窗口；物理操作必须受实际组合的提交边界约束。

## SPEC
1. [LEMMA 1] 开立拒绝缺父、自链、重复身份异义和已收尾父范围；预留拒绝跨 owner 抢占。等价重放不再增加记录，关闭后的身份仍保留。
   - 证明：`tests/001.test.mjs` 的预留、抢占、自链、改挂、重放和终结身份保留均通过。
2. [LEMMA 2, 4] Started、Ended 与 NotStarted 按 lease 和实际实例校验；非法冲突不改变状态。Unknown、旧回执、同容器新实例有独立反例。
   - 证明：`tests/002.test.mjs` 的未知、终态冲突、迟到 Started、容器复用及旧 lease 结算均通过。
3. [LEMMA 3] 子树 drain 后拒绝新 scope/reservation，但接收原预留的迟到 Started 与终态；Cancel/Drain 均不释放 blocker。Close 先完整检查，再关闭全部后代。
   - 证明：`tests/003.test.mjs` 的子树准入、原子关闭、父范围保留、迟到启动、1,500 层遍历和已终结取消结果反例均通过。
4. [LEMMA 5] 请求绑定规范消息；导出记录含递增修订号与摘要链。恢复拒绝缺口、重复、异内容请求、非规范编码及非法状态；查询不写记录，不修复坏历史。
   - 证明：`tests/004.test.mjs` 的实际恢复、规范消息、损坏记录、重算摘要后的非法状态与重放排列均通过。摘要不是签名；无外部可信 head 时不能识别合法前缀的尾部截短。
5. [AXIOM 3; 根 LEMMA 3, 4, 5] 实例私有状态、lease 与查询视图无可变别名；同步重入不暴露半次操作。只有本库源码也能独立构建与测试。
   - 证明：`tests/005.test.mjs` 验证生成对象、别名、访问器和同步重入；隔离构建及删除前三刀产物后的 Node/Bun 安装包消费均通过。
6. [LEMMA 2, 3, 5; 根 SPEC 4] 真实组合在持久预留后启动进程；TERM/超时仍阻止 Work 退休，确认物理结束后才结算 lease。重启仅恢复未完成义务，不重新启动。
   - 证明：`scripts/tests/ownership-composition.test.mjs` 的真实 SQLite 竞争与提交前后丢回执通过；`scripts/tests/ownership-package.test.mjs` 在 Node 25.9.0、Bun 1.3.14 上完成实际 ProcessSession/Work 门禁与协调进程强杀恢复。完整 0.5.0 回归为 275 项通过；这不证明旧宿主已接线。

## 边界

- scope 是收尾范围，不是鉴权角色或物理容器。可有多个 root；parent 为 null 与挂载在父节点下均显式给出。草稿的长期/叶子分类没有实际差异，本轮不预建枚举。
- lease 的摘要防误用，不是对恶意调用者的认证。外侧必须如实提供 Started、Ended、NotStarted 和稳定 incarnation；单靠 PID、文本或超时不能代替。
- 所有权开立后不迁移；这是本轮的明确限制，不把改挂、抢占、跨登记簿合流假装已实现。资源以全新 resourceId 开新轮，旧回执保留在旧身份下。
- 不创建定时器，不按年龄回收，不设隐式容量减一。没有默认重试、通用工作流或注入的物理服务。取消和排空只产生归属事实，信号顺序由组合者决定。
- 本库只能报告已登记资源，不能发现逃逸后代或未登记工作。ProcessSession 的 Closed 也不是完整进程树终止证明；真实组合须说明观测覆盖的物理范围。
- 历史保留，内存随记录增长；单条规范记录上限 64 KiB。内存接受、独立持久消费与旧仓接线是不同验收，本轮只改新仓。


## SessionFamilyTree — 领域会话家族树与祖先图网契约

### 职责与不变量
1. **扁平管理归属（HOST-015 "a son's son is a son"）**：无论托管子会话在逻辑上被谁创建，物理挂载与管理归属均由其家族权威 Family Root 统管；孙会话与子会话具有相同的扁平归属。
2. **权威祖先解析与环路拦截**：通过异步步进查询自底向上解析物理宿主祖先链；遇到已访问节点立即以 `Session ancestry cycle detected at %s` 报错并拒绝建立；底层物理查询失败 fail-closed，严禁无证猜根。
3. **防幽灵复活**：在多跳异步物理查询在途期间，若会话被外部销毁或注销，查询迟到返回时必须放弃写回该分支，禁止幽灵复活已销毁会话。
4. **两阶段中止（Two-Phase Abort）责任守住**：
   - 第一阶段（`markTerminating`）：封闭新子节点准入，将所属全部未终结子会话登记为待终结集合（保留归属记忆），返回确切待中止列表；
   - 第二阶段（`confirmTerminated`）：仅在收到宿主物理退出凭证后方从管理名册彻底注销并在空根时修剪；若底层中止指令失败或超时，会话依然保留在名册与待终结集合中，允许重新中止，绝不失管。
5. **防御性只读暴露**：所有查询和列表接口返回不可变数组快照或纯字符串，严禁向外泄漏内部可变容器别名。
