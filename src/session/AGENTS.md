# session — 资源归属、收尾与家族树

层：内核进程内状态。独立 npm 入口 `wanxiangli/ownership`（源码在 `src/session/`）。在总流程中，对象 `Ownership` 负责外部物理资源的登记、范围归属与收尾，确保每个进程、会话与任务在生命周期终结时均能干净释放，不留孤儿资源。

## 状态所有权
- **Ownership** 独占拥有有根森林作用域、资源预留（Reserved）与运行（Running）状态注册表。
- **SessionFamilyTree** 独占持有基于物理宿主祖先链的会话家族树结构，实现两阶段中止（Two-Phase Abort）。
- **ParentAbortRegistry** 独占持有跨运行时的父级中止回调注册表。

## AXIOM
1. [使用者] 一项外部资源从准备创建到确认结束，都必须有明确的收尾负责人；未知结果不能让资源消失。
2. [使用者] 收尾一个范围不能误伤别的范围；旧实例的迟到回执不能释放复用容器上的新实例。
3. [开发者] 归属规则、物理执行、持久提交与业务退休分别独立，由外侧显式组织。

## LEMMA
1. [AXIOM 1, 2] 作用域组成有根森林，父子关系建立后不可变；资源在所属作用域下独占预留。
2. [AXIOM 1] Reserved 与 Running 状态均阻止范围关闭；已终结资源记录终态后方可安全释放。
3. [AXIOM 1, 2] Drain 阻断新资源准入；Close 仅在整个子树无未终结资源时原子关闭子树。
4. [AXIOM 1] SessionFamilyTree 让托管子会话统一指向其家族根，并在解析祖先链时拦住环路；ParentAbortRegistry 提供锁外快照与重入安全的中止通知。

## SPEC（调用方流程）

1. **资源作用域建立与预留**：
   - 启动任务前在目标作用域登记资源预留；资源实际启动时转为 Running 状态并记录实例标识。
2. **排空与原子关闭**：
   - 任务准备收尾时调用 `Drain` 停止新的资源准入；底层物理资源全部退出后调用 `Close` 原子关闭作用域子树。
3. **会话家族树与两阶段中止**：
   - 通过 `SessionFamilyTree` 跟踪宿主多跳父子关系。触发中止时，第一步调用 `childrenToAbort` 拿到待中止子会话快照（名册不动）；宿主逐个执行中止后，把每个结果 `(childId, isAborted)` 报给 `settleAbort`：只有确切已中止的子会话才移出名册，失败的保留待下次重试。
